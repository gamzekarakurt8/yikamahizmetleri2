# Local SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add local SEO metadata, structured data, sitemap discovery, and visible service-area copy for yikamahizmetleri.com.

**Architecture:** Keep the site as a single-page Create React App. Put static crawler metadata in `public/`, production URL configuration in `package.json`, and visible region copy in the existing data-driven Contact section.

**Tech Stack:** React 17, Create React App, static HTML metadata, JSON-LD, XML sitemap, robots.txt.

---

### Task 1: Static SEO Metadata

**Files:**
- Modify: `public/index.html`
- Modify: `package.json`

- [ ] **Step 1: Update the homepage URL**

Change `package.json` homepage from `https://yikamahizmetleri.net` to `https://yikamahizmetleri.com`.

- [ ] **Step 2: Add static metadata**

In `public/index.html`, replace the empty description and generic title with Turkish local SEO metadata. Add canonical, robots, theme color, Open Graph, Twitter, and LocalBusiness JSON-LD using the production URL, phone, email, social profiles, and service areas.

- [ ] **Step 3: Verify metadata in source**

Run: `rg "yikamahizmetleri.com|LocalBusiness|Tuzla|Gebze|canonical" public/index.html package.json`

Expected: Matches for the canonical domain, structured data type, and service areas.

### Task 2: Crawler Discovery Files

**Files:**
- Modify: `public/robots.txt`
- Modify: `public/sitemap.xml`

- [ ] **Step 1: Add sitemap to robots.txt**

Append `Sitemap: https://yikamahizmetleri.com/sitemap.xml`.

- [ ] **Step 2: Ensure sitemap uses .com**

Set the only `<loc>` value in `public/sitemap.xml` to `https://yikamahizmetleri.com/`.

- [ ] **Step 3: Verify crawler files**

Run: `rg "yikamahizmetleri.com" public/robots.txt public/sitemap.xml`

Expected: Matches in both files.

### Task 3: Visible Local SEO Copy

**Files:**
- Modify: `src/data/data.json`
- Modify: `src/components/contact.jsx`

- [ ] **Step 1: Add service area copy to data**

Add a `serviceAreaText` field under `Contact` describing hali ve koltuk yikama service coverage across Tuzla, Gebze, Pendik, Kartal, Maltepe, Bostanci, Kadikoy, and Umraniye.

- [ ] **Step 2: Render service area copy**

In `Contact`, render `props.data.serviceAreaText` above the existing service-area badges.

- [ ] **Step 3: Verify React build**

Run: `npm run build`

Expected: Build completes successfully.
